Quick start

How installation works

1

Download the bundle for your platform — the version badge always reflects the latest release.

2

Android: allow "install unknown apps" for your browser when prompted; the app will request notification permission on first launch. Windows: unzip and double-click the exe.

3

PWA: tap Install PWA (or browser menu → Install app) while visiting this site.

4

Launch — cached data, rooms and rates are available even with zero connectivity.
